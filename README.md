# Proyecto Calculadora de propinas en python 

# Descripcion del proyecto:

## Este es un proyecto hecho en Python que permite sacar ciertos porcentajes de propinas segun el valor que este gaste en la comida, utilice variables de entrada, de salida, operadores matematicos y por ultimo condicionales para que segun el caso de precio pueda sacar el estimado de la propina segun el caso.
